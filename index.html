Make the introduction worth making.

Discovery is only the start. A link to relevant work, with clear ownership, gives both sides a better reason to talk.

Why build this for Speedrun?

Speedrun already has role discovery, candidate profiles, and a talent team making introductions. This concept explores the handoff between them: help a candidate explain the work behind a profile before asking for someone’s time.

What would I test first?

Invite a small opt-in group to prepare one reviewed work sample. Compare completed intro requests and mutually accepted conversations with the existing flow. Ask founders whether the evidence helped them decide. Measure replies and spam complaints together; more messages alone would not prove success.

What works in this prototype?

Public role lookup, title and company filtering, a remote filter, editable project examples, a live introduction preview, and copy-to-clipboard. The text is assembled from your inputs without an AI model. There is no account, application submission, or connection to private founder tools.

What happens to my information?

Your edits stay in this tab’s memory and disappear when you reload or close it. Only public job requests go to Speedrun. No project text is sent, saved to a server, or put in the URL. If live roles fail to load, a dated public snapshot is clearly marked.

What would I build next?

Start with candidate and talent-team feedback. If this helps, connect it to the existing profile and intro workflow with explicit sharing consent, access controls, deletion, and role-availability checks. Validate a work sample’s relevance through human review before adding AI assistance.
